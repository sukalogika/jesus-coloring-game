# Jesus Coloring Game 🎨

An interactive, web-based Jesus and Bible coloring game designed for kids and Sunday school activities. Built lightweight and fast so anyone can play directly in their browser without installation.

👉 **[Play Live Demo Here](https://sukalogika.com/games/mewarnai-yesus/)**

---

## ✨ Features
* **Kid-Friendly Interface:** Simple tap-to-fill or brush controls suitable for children.
* **Bible-Themed Illustrations:** Engaging illustrations centered around Jesus and biblical stories.
* **Cross-Platform:** Works smoothly on desktop browsers, tablets, and smartphones.
* **Zero Setup:** Pure web technologies; runs instantly without plugins.
